# Алгоритм подсистемы «Материалы» (модуль 2)

## Вывод списка материалов
1. Открыть главное окно, загрузить логотип и иконку из папки Resources.
2. Подключиться к БД AromaDom.
   - Ошибка подключения → показать сообщение об ошибке, список оставить пустым, приложение не закрывать.
3. Выбрать материалы с наименованием типа (Materials JOIN MaterialTypes).
4. Выбрать рецептуры (MaterialProducts: MaterialId, Quantity) и сгруппировать по материалу.
5. Для каждого материала вызвать расчёт требуемого количества (ниже).
6. Вывести материалы карточками: «Тип | Наименование», минимальное количество,
   количество на складе, цена и единица измерения, требуемое количество.

## Функция расчёта требуемого количества
`MaterialCalculator.CalculateRequiredQuantity(quantitiesPerProduct)`

1. Если список не передан → вернуть 0.
2. total = 0.
3. Для каждого количества материала на единицу продукции q:
   если q > 0 → total = total + q.
4. Вернуть total, округлённое до 2 знаков после запятой.

Пример: «Соевый воск премиум» участвует в 8 рецептурах, сумма = 1,635 → 1,64 кг.
